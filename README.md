# MB2 Shortcodes Filter (Moodle Plugin)

## Overview
MB2 Shortcodes is a Moodle text filter plugin that allows you to use shortcodes inside Moodle content and automatically replace them with dynamic HTML output.

---

## Features
- Simple shortcode parsing system
- Lightweight and fast
- Compatible with Moodle text filters
- Easy to extend with custom shortcodes
- Supports shortcode parameters
